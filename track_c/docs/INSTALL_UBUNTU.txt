UBUNTU PREREQUISITES

sudo apt update
sudo apt install -y mininet openvswitch-switch python3-pip ethtool iproute2 iputils-ping

Install Ryu in a compatible Python environment if ryu-manager is not already available
(Ryu 4.34 needs an older Python/eventlet, e.g. Python 3.9 with eventlet==0.30.2).
Then verify:
  mn --version
  ovs-vsctl --version
  ryu-manager --version

Run the automated Track C execution from the repository root:
  sudo ./track_c/ubuntu_runner/run_track_c_mininet.sh

Results are written to track_c/results/actual_sdn_results/ (SUMMARY.txt lists PASS/FAIL per test;
the script exits non-zero if any test fails).

Delay tests (P2, P4) need the tc "netem" kernel module. If it is missing the runner marks P2 as
SKIPPED and P4 as "load only" instead of silently producing wrong numbers. Stock Ubuntu has netem.
If the Open vSwitch kernel module is missing, the runner falls back to the userspace datapath and
disables TX checksum offload on the hosts automatically.

Do not run the old interactive d2_topology.py for the Track C demo; the automated runner
is provided so the entire experiment can be performed from one command.
