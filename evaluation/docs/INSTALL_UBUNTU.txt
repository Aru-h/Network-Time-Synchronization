UBUNTU PREREQUISITES

  sudo apt update
  sudo apt install -y mininet openvswitch-switch python3-pip iperf ethtool iproute2 iputils-ping

Ryu 4.34 needs an older Python/eventlet than the newest Pythons (e.g. Python 3.11 venv with a compatible
eventlet). The launcher looks for ryu-manager on PATH, then in ~/topic23-venv and ~/.pyenv/versions/*/bin.

Check the environment (no test is run):
  sudo env EVAL_CHECK_ONLY=1 ./evaluation/ubuntu_runner/run_evaluation.sh

Run everything, from the repository root:
  sudo ./run_d2.sh

Results: evaluation/results/actual_sdn_results/ (SUMMARY.txt first). The folder is wiped and rewritten each run.

Notes
- netem (kernel module sch_netem) is needed for P2 and P4. Without it they are reported SKIPPED, never PASS.
- If the Open vSwitch kernel module is missing the runner falls back to the userspace datapath and disables TX
  checksum offload on the hosts automatically.
- Without iperf the runner uses the Python load generator, which may not reach the target rate; the congestion
  check then reports "NO CONGESTION ACHIEVED" (added RTT below 5 ms) instead of passing.
- Do not use the old interactive d2_topology.py for the evaluation: its links are not shaped, so there is no bottleneck.
