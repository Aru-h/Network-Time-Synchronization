# Topic 23 — D2 Extension

This folder is the D2 extension of the D1 project.

Use `controller/d2_adaptive_controller.py` and `mininet/d2_topology.py` for
the D2 demo.

The D2 controller adds:
- periodic port statistics
- traffic classification
- dynamic synchronization priority
- background-load awareness
- recovery-friendly learning behavior

- `docs/D2_REPORT.md`
- `docs/D2_DEMO_SCRIPT.md`
